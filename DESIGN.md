# ПроРельс — отдельный лендинг

Задача: помочь снабженцу, подрядчику и промышленному предприятию выбрать материалы ВСП и перейти в существующий каталог prorelsa.ru или связаться с отделом продаж.

Направление: промышленная точность, реальные материалы, фирменный оранжевый. Светлая шапка с оригинальным логотипом; графитовый первый экран с фотографией пути; спокойные светлые секции. Основной выразительный приём — диагональный стык фотографии и текста под углом знака из логотипа. Он используется только на первом экране.

Цвета: signal #FF5B00; graphite #141E26; paper #FFFFFF; surface #F3F5F6; secondary #5B6871; line #DDE3E7. На оранжевых кнопках тёмный текст; оранжевый текст на белом заменён тёмным оттенком #B64000 для контраста.

Шрифты: Manrope Variable 600–800 для заголовков; Golos Text Variable 400–600 для основного текста. Кириллица, локальные WOFF2, font-display: swap. Текст и изображения доступны сразу, без анимации появления, скрывающей содержание.

Композиция:

```text
Логотип                 Продукция · О компании · Доставка       Телефон
Текст + две CTA          /                  Фотография пути
Комплектация              Документы                 Доставка
Категории: 3 × 2, точные ссылки на действующий каталог
Кому поставляем: четыре отрасли
Компания и четыре принципа комплектации
Доставка: Зеленодольск → Россия и СНГ, три шага заказа
Вопросы о поставке
Блог: три карточки → список статей → страница с оглавлением
Контакты + отправить спецификацию / открыть каталог
Юридическое лицо, политика, ссылка на основной сайт
```

Отказ от шаблонных приёмов: никаких выдуманных логотипов клиентов, отзывов, счётчиков или карточек с произвольной нумерацией. Нумерация только у последовательных этапов поставки. Карта не нужна для выбора доставки: географию объясняет текст и маршрут от склада к объекту.

Референс https://жд-склад.рф задаёт объём и поведение внешних CTA, а не копирование его текста и дизайна. Ассортимент, реквизиты и контакты сверены с https://prorelsa.ru/ 10.10.2026. Логотип предоставлен пользователем. Остальные изображения взяты из исходного проекта railways-catalog.
