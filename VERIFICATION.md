## SEO

Проверялся фактический HTML работающего production-сервера, а не только исходные компоненты. `npm run verify:seo` прошёл в обоих режимах:

| Проверка | Preview без домена | Режим публикации с тестовым origin |
| --- | --- | --- |
| Главная | 200, контент в HTML, lang=ru, один H1 | То же |
| Robots meta | noindex, nofollow | index, follow |
| X-Robots-Tag | noindex, nofollow | Отсутствует |
| Canonical | Отсутствует | Собственный origin лендинга |
| og:url / WebSite | Без придуманного публичного URL | Совпадают с canonical origin |
| Sitemap | Без URL | Только корень лендинга |
| robots.txt | Allow /, поисковик может прочитать noindex | Allow / и абсолютный Sitemap |
| JSON-LD | Organization, подтверждённые реквизиты | Organization и WebSite |
| OG image | PNG, 200, 1200×630 | То же, публичный URL от SITE_URL |
| Отсутствующая страница | HTTP 404, noindex, без canonical | То же |

Режим публикации проверялся **только локально** с синтетическим `https://landing-validation.prorels.ru`. Он не является выбранным доменом и не публиковался. После проверки выполнена новая сборка без этого origin, `verify:seo` пройден повторно. Финальное состояние — noindex. Завершающий слеш canonical нормализуется Next.js; тест сравнивает эквивалентные абсолютные URL.

## Интерфейс и доступность

- В браузере проверены ширины 320, 390, 768, 1024, 1440 и 1920 px: горизонтального переполнения нет, H1 один, пустых ссылок нет.
- Просмотрены первый экран, категории, доставка, контакты и футер, а также полная настольная страница.
- Все шесть изображений категорий загружаются. Изображение тёмного логотипа проходит через оптимизатор Next.js с HTTP 200.
- Мобильное меню открывается и закрывается. Выбор «Доставка» закрывает меню; раздел расположен ниже закреплённой шапки. Escape закрывает меню и возвращает фокус кнопке.
- FAQ раскрывает ответ нативным details/summary.
- Нажатие «Смотреть каталог» действительно открывает https://prorelsa.ru/catalog. Переход назад возвращает лендинг.
- У телефона и почты настоящие tel/mailto-ссылки. Для спецификации в mailto заполнена тема письма. Письма и звонки во время проверки не отправлялись.
- axe-core: 0 нарушений по проверяемым правилам WCAG 2 A/AA и 2.1 A/AA на мобильной и настольной ширине (25/24 прошедших проверок). Это автоматическая проверка, не полная сертификация доступности. Тестовый скрипт удалён, в финальную сборку не включён.
- prefers-reduced-motion отключает плавную прокрутку и переходы. Критический контент не скрывается анимациями.
